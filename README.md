# One Door Closed

PLS 210 · Presentation #2 as a static website (no build step).

## Publish on GitHub Pages

1. Create a new GitHub repository (for example `one-door-closed`).
2. Upload `index.html`, `style.css`, `script.js` and `.nojekyll` to the repository root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/one-door-closed/`.

## Edit

- Fonts and colours are variables at the top of `style.css`.
- Slides are `<section class="slide">` blocks in `index.html`.
- Reference entries marked with a yellow "check" tag need verifying; delete the tag once done.
